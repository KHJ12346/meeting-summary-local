# 회의록 요약 서비스 (로컬)

노트북의 `http://127.0.0.1:8765` 웹페이지에서 회의를 녹음하고, 전사·요약한 결과를 노트북에 보관합니다.
PRD: 프로젝트와 함께 관리하는 "회의록 요약 서비스 PRD" 문서(v0.2).

## 실행

1. Node.js 20 이상이 필요합니다. (외부 패키지는 필요 없습니다. `npm install` 불필요)
2. `시작.bat`을 더블클릭하거나 `node server.js`를 실행합니다. 브라우저가 자동으로 열립니다.
3. 종료는 창에서 `Ctrl+C`.

## 처리 방식 (설정 화면에서 선택)

| | 기본값 | 외부 전송 |
|---|---|---|
| 전사 | 로컬 (whisper.cpp) | 없음 |
| 요약 | 로컬 (Ollama) | 없음 |
| Groq 선택 시 | 전사·요약 각각 선택 가능 | **있음** — 처리 전에 매번 동의를 확인 |

**기본은 로컬입니다.** Groq는 설정에서 직접 켠 경우에만 쓰고, 켜도 녹음 종료/재처리 때마다 동의 창이 뜹니다(동의 없이는 서버가 처리를 거부합니다). 사용 이력은 `회의록데이터\audit.log`에 내용 없이 남습니다.

### Groq 사용
1. `.env.example`을 `.env`로 복사하고 `GROQ_API_KEY=` 뒤에 키를 넣습니다. (키는 화면에 표시되지 않습니다)
2. 프로그램을 다시 시작하고, 설정에서 전사/요약을 Groq로 선택합니다.
3. 무료 사용 한도(분당·일일 요청, 오디오 크기)는 Groq 콘솔에서 확인하세요. 한도를 넘으면 처리가 실패하고 녹음은 보존되며, 잠시 뒤 [이어서 다시 처리]를 누르면 이미 전사된 구간은 건너뜁니다.
4. 오디오 파일 크기 상한을 피하려고 녹음을 10분(설정 가능) 단위 파일로 나눠 저장합니다.

### 로컬 사용 (오프라인) — 별도 설치 필요
이 프로그램에는 음성인식 엔진이 들어 있지 않습니다. 인터넷 PC에서 받아 사내 반입 절차(해시 검증 포함)를 거쳐 설치하세요.
- **ffmpeg** (녹음 변환용)
- **whisper.cpp** 의 `whisper-cli.exe` 와 모델 파일(`.bin`, 예: large-v3 계열)
- **Ollama** 와 요약 모델 (모델별 라이선스에서 업무 사용 가능 여부 확인)

설정 화면에 각 경로와 모델명을 입력합니다. Ollama 주소는 이 노트북(127.0.0.1)만 허용됩니다.

## 데이터 저장

```
회의록데이터\
 ├ settings.json
 ├ audit.log                  (생성·종료·처리·내보내기·삭제 기록, 내용 없음)
 └ meetings\<날짜-시간-코드>\
     ├ seg-000.webm …         (녹음 원본, 구간별 파일)
     ├ transcript.json        (타임스탬프 포함 전사문)
     ├ summary.md             (요약, 편집 가능)
     └ meta.json              (회의명·참석자·상태·동의/처리 이력)
```
위치를 바꾸려면 `.env`의 `DATA_DIR`을 지정합니다. **노트북 분실·도난에 대비해 BitLocker 등 디스크 암호화를 켜 두세요.** 이 프로그램은 저장 데이터를 자체 암호화하지 않습니다.

## 보안 설계
- 웹서버는 `127.0.0.1`에만 바인딩됩니다. 같은 네트워크의 다른 PC는 접속할 수 없습니다.
- Host/Origin 검사로 DNS 리바인딩과 다른 웹사이트에서의 요청을 막습니다.
- 화면에서 외부 CDN·폰트·스크립트를 쓰지 않으며, CSP로 외부 연결을 막습니다. (Groq 호출은 서버가 하고, 브라우저는 외부로 연결하지 않습니다)
- API 키는 `.env`/환경 변수에서만 읽고 화면·응답·로그에 내보내지 않습니다. `.env`는 평문 파일이므로 폴더 접근 권한에 유의하세요.
- 외부 의존 패키지가 없어 공급망 점검 대상은 Node.js 본체뿐입니다.

## 테스트
```
node --test test/
```
가짜 Groq/Ollama 서버로 동의 강제, 구간 합치기, 중단 복구, 삭제, 경로 조작·Host/Origin 차단 등을 검증합니다.

## 알려진 한계 (v0.1)
- 실제 Groq 서버와 실제 마이크는 이 개발 환경에서 검증하지 못했습니다(키·마이크 없음). 가짜 서버와 가짜 오디오 스트림으로만 확인했습니다. **처음 실사용할 때 짧은 테스트 녹음으로 확인하세요.**
- 로컬 전사(ffmpeg + whisper.cpp)는 설치되어 있지 않아 실행을 검증하지 못했습니다. Ollama 요약은 가짜 서버로 검증했습니다.
- 미구현: 화자 구분, 전사문 편집, 문장 클릭 시 해당 위치 재생, 용어 사전, Word/HWP 내보내기(현재 .md), 앱 PIN 잠금, 백업, 보관 기간 알림.
- 브라우저 녹음은 webm이라 재생 막대에 전체 길이가 표시되지 않을 수 있습니다.
